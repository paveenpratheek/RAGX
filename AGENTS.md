# Project Harness

This repository keeps a GitX record (`.gitx`). Work the GitX way: follow the
`gitx-workflow` skill - catch up with `gitx_thought_catch_up` at the start,
check a plan against GitX before building, record decisions as they happen
with `gitx_thought_record`, cite them in comments, and commit with the GitX
trailer block after `gitx_find_related`.
