    Images

    Each figure and scanned page of a new document is sent to Anthropic once, through your Claude subscription, and Claude writes out its text and what it shows, so the words and numbers in images can be searched. Readings are kept, so an image is never read twice. Documents already in the library are read only when you press Read figures now, at most 50 images at a time.

    A document can link images on this computer - NoteX links each image of a File Fabric canvas under its place. Under an answer, RAGX shows the images of the places it cited, opening each where it is; only images inside these folders are ever opened.
